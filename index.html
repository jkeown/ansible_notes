ansible.cfg

Ansible Config

Usually in project's root directory (project specific)


  [defaults]
  inventory = inventory
  host_key_checking = false
  remote_user = username
  
  [privilege escalation] 🛈
  become = true
  become_user = root
  become_method = sudo

ansible --versionShows which ansible.cfg is being used amongst other info

inventory

Inventory File

Usually in project's root directory (project specific)


  vm9

  [webservers]
  vm1
  vm8

  [dbservers]
  vm2
  vm3
  vm5
  vm6

  [test]
  vm4
  v7

  [production:children]
  webservers
  dbservers

ansible-inventory --graphList inventory as ASCII tree structure

ansible-inventory --listList inventory as JSON

Ad hoc Commands

Common commands

ansible HOSTS -m pingTest connectivity to managed nodes

ansible HOSTS -a "REMOTE_COMMAND"Execute cli commands

ansible HOSTS -m shell -a "REMOTE_COMMAND"Execute cli commands when above doesn't work. Sometimes the terminal shell is necessary for the command to run

Playbook Header

Always be mindful of indentation


  ---
  - name: Playbook Header Example
    hosts: all
    become: true
    vars:
        ...
    tasks:
      - name: Task #1
        ...

Variables

Vars in Playbook Header

Always be mindful of indentation


  ---
  ...
    vars:
  # Single Variables
      var1: var1_value
      var2: var2_value
    
  # Single List (Array)
      db_users:
        - user1
        - user2
        - user3
    
  # Single Dictionary
      db_user_roles:
        admin: primary
        readonly: restricted
        backup_user: system
    
  # List of Dictionaries
      db_users_perms:
        - name: admin
          privileges: all
        - name: readonly
          privileges: select_only
